# Last Text at One Percent

The last text message a phone sends at one percent battery, in the phone's own voice. It has been clinging to 1% for hours while its owner never charged it, so instead of a generic battery warning it sends an accusation — reframing its own death as a crime, then signing off. Written by `main.py` to `/output/entry.txt` — deterministic, no network, same bytes on every run.
